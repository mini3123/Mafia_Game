# 아진 마피아

친구들과 브라우저로 즐기는 실시간 마피아 게임. 방 코드로 입장하고 앱 안 채팅으로 토론한다.

## 규칙

5~12명이 참여한다. 역할은 **마피아 · 스파이 · 의사 · 경찰 · 시민** 다섯 가지.

하루는 이렇게 흐른다.

```
밤 30초 → 낮 토론 120초 → 지목 투표 30초 → 최후 변론 30초 → 찬반 투표 20초 → 밤
```

핵심 규칙 몇 가지.

- 사망자는 **직업이 아니라 진영만** 공개된다. 의사가 죽어도 "시민"으로만 뜬다.
- **스파이는 마피아 팀**이지만 경찰 조사에 "마피아 아님"으로 나오고, 죽어도 "시민"으로 공개된다. 접선에 성공하면 즉시 마피아 채팅에 합류한다.
- 승리 판정에서 스파이는 마피아로 세지 않는다. 다만 마피아가 이기면 함께 이긴다.
- 죽은 사람은 유령 채팅으로 자기들끼리 대화할 수 있고, 그 메시지는 산 사람에게 **전송조차 되지 않는다.**

## 개발

```bash
npm install
npm run dev:server   # 터미널 1 — 3000 포트
npm run dev:client   # 터미널 2 — 5173 포트
```

브라우저 창을 5개 이상 열어 각각 방에 들어가면 혼자서도 시험해볼 수 있다.

## 테스트

```bash
npm test              # 서버 + 클라이언트 전체
npm run test:server   # 서버만
```

게임 규칙은 소켓을 모르는 순수 로직이라 서버를 띄우지 않고 검증된다.
그중 가장 중요한 것은 `server/test/view.test.js`의 **정보 누출 테스트**다.
클라이언트로 나가는 데이터를 재귀적으로 훑어 남의 역할이 단 한 조각도 섞이지
않았는지 확인한다.

## 배포

```bash
npm run build   # 클라이언트를 client/dist로 빌드
npm start       # 서버가 소켓과 정적 파일을 함께 서빙 (3000 포트)
```

Docker를 쓴다면 `docker build -t mafia . && docker run -p 3000:3000 mafia`.

DB를 쓰지 않는다. **게임 상태는 서버 메모리에만 있으므로 서버를 재시작하면
진행 중이던 게임은 사라진다.** 친구들끼리 한 판 하는 용도라 이 정도면 충분하다.

## 구조

```
server/src/game/   소켓을 모르는 순수 게임 로직
  view.js            viewFor() — 비밀 정보가 나가는 유일한 출구
server/src/        방 관리 · 타이머 · 소켓 배선
client/src/        React 화면
```

서버가 게임의 유일한 진실이다. 클라이언트는 행동의 *의도*만 보내고,
유효성 판단과 상태 변경은 전부 서버가 한다. 화면에서 막는 것은 편의일 뿐이다.

설계 문서와 구현 계획은 `docs/superpowers/` 아래에 있다(git에는 포함하지 않는다).
